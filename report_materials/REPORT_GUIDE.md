# Final Project Report Materials

This folder is a working pack for writing the report. It contains selected
figures and result tables generated by the project notebooks, plus this
rubric-mapped outline. It is not a finished report: explain the results in your
own words, cite the original sources, and follow the course formatting and word
limit.

## Result provenance

- Dataset: 23,483 images, 17 classes, Apple/Potato/Tomato.
- Split: 18,786 train / 2,348 validation / 2,349 test (stratified).
- The ten saved prediction files were checked against `data/splits.csv`: each
  has 2,349 unique paths and exactly matches the same test split.
- Results below are from the currently saved full-test outputs, not the
  quick-test subset.
- Confidence intervals and significance tests quantify uncertainty for this
  one split. They do not measure variation across random training seeds.

### Discussion, limitations, and conclusion

Discuss what the models learned, the trade-off between performance and cost,
which classes remain difficult, and whether metadata/text comparisons support
the hypothesis being tested. Explicitly acknowledge:

- PlantVillage's controlled backgrounds and limited external validity.
- Class-level project-authored text/metadata and the risk of label leakage if
  used as prediction inputs.
- One split and seed, possible near-duplicate images, and independence
  assumptions in the statistical tests.
- Different model tuning effort and the smaller input resolution of the
  NumPy implementation.
- No object-detection model was implemented; this project evaluates image
  classification.

## Current result snapshot

| Model | Accuracy | Macro-F1 | 95% bootstrap CI for macro-F1 |
|---|---:|---:|---:|
| ResNet18 fine-tuned | 0.9877 | 0.9885 | 0.9840–0.9925 |
| SVM deep features | 0.9728 | 0.9642 | 0.9527–0.9741 |
| Custom CNN (PyTorch) | 0.9689 | 0.9586 | 0.9451–0.9693 |
| Image + crop fusion | 0.9510 | 0.9465 | 0.9343–0.9569 |
| Logistic regression, image-only control | 0.9468 | 0.9419 | 0.9298–0.9525 |
| Image-text alignment | 0.9434 | 0.9337 | 0.9185–0.9466 |
| Random forest, deep features | 0.8723 | 0.8035 | 0.7763–0.8269 |
| SVM, hand-crafted features | 0.8501 | 0.7968 | 0.7679–0.8204 |
| NumPy CNN from scratch (32 x 32) | 0.7569 | 0.7101 | 0.6858–0.7317 |
| Random forest, hand-crafted features | 0.7531 | 0.6116 | 0.5907–0.6305 |

These are observed results for the current single test split; do not generalize
them to field photographs or other splits without additional evaluation.
